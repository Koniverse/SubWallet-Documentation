### Earning information & parameters for supported tokens

<sup>_2_</sup>_&#x20;For added convenience, SubWallet only supports auto-compound staking on Tanssi, which automatically compounds staking rewards into the staked funds._

<sup>_3_</sup>_&#x20;Effective March 18, 2026, staking rewards on Manta Atlantic have been discontinued, and users are no longer able to stake MANTA. This change is part of the planned roadmap leading to the shutdown of the Manta Atlantic network on August 1, 2026. Check out this_ [_announcement_](https://x.com/MantaNetwork/status/2031641845995024845?s=20) _for more details._
