# Add new networks unavailable in pre-defined list from dApp

{% hint style="info" %}
Currently, SubWallet supports adding new EVM & Substrate networks.
{% endhint %}

**Step 1**: On the SubWallet homepage, press the "**dApps**" tab at the bottom of the screen.

<figure><img src="../../.gitbook/assets/Screenshot_1 (7).png" alt="" width="272"><figcaption></figcaption></figure>

**Step 2**: Search for the dApp you want to access by typing on the search bar or selecting a dApp in the Recommended section.

_In this example, we are connecting to Chainlist._

{% hint style="warning" %}
As ChainList is a list of EVM networks, MetaMask will be its default wallet for connecting. Therefore, if you want to connect via SubWallet, disable the MetaMask extension first.
{% endhint %}

<div><figure><img src="../../.gitbook/assets/Screenshot_2 (10).png" alt="" width="272"><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/Screenshot_33 (7).png" alt="" width="272"><figcaption></figcaption></figure></div>

**Step 3:** After successfully accessing the dApp, scroll down and select the network you want to add by typing on the search bar. Once done, hit "**Connect Wallet**".

_In this example, we want to add the PulseChain network._

<div><figure><img src="../../.gitbook/assets/Screenshot_34 (8).png" alt="" width="272"><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/Screenshot_35 (5).png" alt="" width="272"><figcaption></figcaption></figure></div>

**Step 4:** A popup will appear. Select the account(s) in which you want to add the network, then press "**Connect**".

<div><figure><img src="../../.gitbook/assets/Screenshot_36 (5).png" alt="" width="272"><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/Screenshot_37 (5).png" alt="" width="272"><figcaption></figcaption></figure></div>

**Step 5**: Once you've selected the account(s), the initial popup will be closed, and another popup will appear, asking you to confirm the add network request. Check the request details, then hit "**Approve**" to add the network.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot_38 (6).png" alt="" width="272"><figcaption></figcaption></figure>

**Step 6**: You've successfully added a custom network from dApp! To find your newly added network, follow this [guide](../../extension-user-guide/network-management/customize-your-networks/manage-custom-networks.md).

<figure><img src="../../.gitbook/assets/Screenshot_39 (5).png" alt="" width="272"><figcaption></figcaption></figure>
