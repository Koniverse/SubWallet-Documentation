# Sign transactions on dApp

{% hint style="info" %}
The user interface (UI) and buttons you encounter will vary based on the specific designs of each dApp/website.
{% endhint %}

**Step 1:** Open the dApp and connect your account(s) to it via this [guide](https://app.gitbook.com/o/CyPU0v2iA12ILmupTKub/s/-Lh39Kwxa1xxZM9WX_Bs/~/changes/736/web-dashboard-user-guide/connect-and-sign-transactions-on-dapps-with-walletconnect/connect-dapps-with-walletconnect#connect-dapp-with-walletconnect).

_We are connecting to Moonbeam App in this instance. Once you've connected your account(s) to Moonbeam App, it will display as follows:_

<figure><img src="../../.gitbook/assets/image (2125).png" alt=""><figcaption></figcaption></figure>

**Step 2:** Fill in the necessary information for the transaction.&#x20;

_In this example, we will be staking DEV, the native token of the Moonbase Alpha network._

<figure><img src="../../.gitbook/assets/image (2126).png" alt=""><figcaption></figcaption></figure>

Once done, click "**STAKE**".&#x20;

<figure><img src="../../.gitbook/assets/image (2127).png" alt=""><figcaption></figcaption></figure>

**Step 3**: Switch to the SubWallet Web dashboard tab. The SubWallet popup screen will appear. Check the transaction details, then click "**Approve**" to proceed.&#x20;

<figure><img src="../../.gitbook/assets/image (2128).png" alt=""><figcaption></figcaption></figure>

**Step 4**: You've successfully signed a transaction on a dApp! If the transaction is successful, you'll see the change in the balance of each token.

<figure><img src="../../.gitbook/assets/image (2129).png" alt=""><figcaption></figcaption></figure>
