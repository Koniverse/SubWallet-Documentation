# Import NFTs

### Supported NFT standards

Currently, SubWallet supports the following token standards for NFT (also known as _non-fungible tokens_):

* _**ERC-721**_: Most widely used token standard, used on most EVM-compatible networks
* _**ERC-1155**_: Supported on the RARI Chain network
* _**PSP-34**_: Supported on the Aleph Zero & Aleph Zero testnet network

### Add NFTs to your account

**Step 1**: On the SubWallet homepage, select the "**NFTs**" tab right next to the "**Tokens**" tab.

<figure><img src="../../../.gitbook/assets/image (2100).png" alt=""><figcaption></figcaption></figure>

**Step 2**: Click "**Import collectible**" at the bottom of the screen to start adding NFTs.

<figure><img src="../../../.gitbook/assets/image (2103).png" alt=""><figcaption></figcaption></figure>

**Step 3**: A popup will appear on the right side.&#x20;

Enter the NFT details. You will need to specify the network on which you have the NFT and the NFT contract address.&#x20;

<figure><img src="../../../.gitbook/assets/image (2104).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
SubWallet will automatically perform an on-chain search to fill in details such as NFT type and NFT collection name.
{% endhint %}

<figure><img src="../../../.gitbook/assets/image (2105).png" alt=""><figcaption></figcaption></figure>

Once done, click "**Import**".

**Step 4**: The popup will close. Your newly imported NFT (in this case, _PayRue NFT_) should be visible there.

<figure><img src="../../../.gitbook/assets/image (2106).png" alt=""><figcaption></figcaption></figure>
