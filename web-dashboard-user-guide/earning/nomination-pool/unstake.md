# Unstake

**Step 1**: On the SubWallet homepage, select the "**Earning**" tab on the sidebar.&#x20;

<figure><img src="../../../.gitbook/assets/image (2240).png" alt=""><figcaption></figcaption></figure>

**Step 2**: In the Your earning positions screen, click "**Unstake**" to start the unstaking process.

<figure><img src="../../../.gitbook/assets/image (2232).png" alt=""><figcaption></figcaption></figure>

**Step 3:** A popup screen will appear on the right side. Enter the amount you want to unstake, then click "**Unstake**" to proceed.

{% hint style="info" %}
You can choose to unstake part of your funds or unstake all. Keep in mind that if you don't want to unstake all, you need to keep the staked balance above the minimum active stake so that you can claim rewards, unstake, and withdraw them in the future.
{% endhint %}

<figure><img src="../../../.gitbook/assets/image (2233).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
If you are in "**All accounts**" mode, you will need to select the account for which you want to unstake.

![](<../../../.gitbook/assets/image (2234).png>) ![](<../../../.gitbook/assets/image (2235).png>)
{% endhint %}

**Step 4**: Check the information and confirm your request by clicking "**Approve**".&#x20;

<figure><img src="../../../.gitbook/assets/image (2236).png" alt=""><figcaption></figcaption></figure>

**Step 5:** Your request has been submitted!

<figure><img src="../../../.gitbook/assets/image (2237).png" alt=""><figcaption></figcaption></figure>

You can either click "**Back to home**" to return to the homepage or "**View transaction**" to see transaction details in the History tab.

{% hint style="info" %}
If you click "**View transaction**", SubWallet will show you the latest transaction record in your transaction history along with the extrinsic hash of the transfer.&#x20;

![](<../../../.gitbook/assets/image (2238).png>)
{% endhint %}
