# Understand account types

Currently, SubWallet supports 5 account types, each with its unique features:

There are 5 types of solo accounts:</p><ul><li>Substrate (Polkadot) account</li><li>EVM (Ethereum) account</li><li>TON account</li><li>Cardano account</li><li>Bitcoin account*</li></ul></td><td><img src="../../.gitbook/assets/Screenshot_150.png" alt=""><img src="../../.gitbook/assets/Screenshot_151 (1).png" alt=""><img src="../../.gitbook/assets/Screenshot_152 (1).png" alt=""><br><img src="../../.gitbook/assets/image (2) (4).png" alt=""><img src="../../.gitbook/assets/image (2023).png" alt=""></td></tr><tr><td>Watch-only account</td><td>Solo accounts in which you can <strong>only view</strong> but cannot make any transactions</td><td><img src="../../.gitbook/assets/Screenshot_154.png" alt=""></td></tr><tr><td>Ledger account</td><td>Solo accounts created on Ledger devices</td><td><img src="../../.gitbook/assets/Screenshot_153 (1).png" alt=""></td></tr><tr><td>QR-signer account</td><td>Solo accounts created via the Polkadot Vault app or Keystone devices</td><td><img src="../../.gitbook/assets/Screenshot_155.png" alt=""></td></tr></tbody></table>

_(\*): Currently, SubWallet supports 3 Bitcoin address types in Bitcoin-supported accounts:_

* _Legacy Bitcoin address (BIP-44)_
* _Native SegWit Bitcoin address (BIP-84)_
* _Taproot Bitcoin address (BIP-86)_
